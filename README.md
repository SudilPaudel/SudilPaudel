## About Me

I’m a Full-Stack Web Developer with 1.5+ years of experience building modern web applications using the MERN stack and related frontend technologies. I focus on creating scalable, maintainable, and user-centered products with strong frontend architecture, reliable backend systems, and clean developer workflows.

My work spans full-stack product development, reusable UI components, REST API integration, authentication systems, admin dashboards, and real-world business applications. I enjoy turning ideas into functional products and continuously improving through hands-on development.

### What I work with
- Full-stack web application development using the MERN stack
- Frontend architecture with React, Next.js, TypeScript, and Tailwind CSS
- Backend API development using Node.js, Express.js, MongoDB, and PostgreSQL
- Authentication, protected routes, dashboard systems, and admin workflows
- Responsive interfaces, reusable components, and maintainable project structure
